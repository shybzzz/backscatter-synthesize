# backscatter-synthesize

Numerical synthesis of the backscattered signal of a dual-element (pitch-catch, укр. «роздільно-суміщений») ultrasonic piezoelectric transducer for NDT (flaw detection, thickness gauging). The model is built incrementally, stage by stage of the physical signal chain; the owner describes each next stage before it is implemented — do not implement stages ahead of being asked.

## Commands

- Run: `python main.py` (regenerates all figures in `images/`, then opens plot windows; set `MPLBACKEND=Agg` when headless)
- Install deps: `pip install -r requirements.txt` (NumPy, SciPy, matplotlib; Python >= 3.10)
- No test suite yet; verification is done ad hoc (numeric checks + inspecting saved figures).

## Structure

- `main.py` — entry point; builds the signal chain, saves all figures to `images/`
- `backscatter/pulse.py` — excitation pulse: Gaussian-enveloped sine (README formula (1))
- `backscatter/pulse_scipy.py` — same pulse via `scipy.signal.gausspulse`; cross-check of `pulse.py`, agrees to ~1e-15
- `backscatter/echoes.py` — generic reverberation engine `add_scatterer_echoes`: echo train from a partial reflector at depth z, amplitudes S · r^k · 10^(−α·2zk/20), arrivals t0 + k·2z/c; `scale`/`time_offset` describe the transfer path outside the cavity; optional hooks `sensitivity(z)` (extra amplitude factor) and `path_length(z)` (two-way path, sets arrival time and attenuation), both functions of the unfolded one-way depth k·z, generalize the train to oblique geometries
- `backscatter/specimen.py` — steel defaults + `add_backwall_echoes` wrapper (z = d, r = 1)
- `backscatter/transducer.py` — delay-line model: piezo on plexiglass prism; `synthesize_transducer_signal` = prism reverberation train + backwall train seen through the prism (Stokes relations, energy split T = 0.8 transmitted as working assumption, amplitude r = sqrt(1−T)); first-order paths only
- `backscatter/flaw.py` — flawed specimen: plane partial reflector at depth z_f (amplitude reflection sqrt(R_f), through-transmission 1−R_f per crossing); three echo families composed from add_scatterer_echoes; reduces to transducer model at R_f = 0
- `backscatter/structural_noise.py` — grain noise: N random-depth scatterers (uniform default, configurable), per-scatterer energy from total backscatter R_s via eps = 1−(1−R_s)^(1/N); single-scattering echoes with random signs; coherent backwall train weakened by (1−R_s)^k; frozen microstructure re-illuminated each reverberation; reproducible via rng seed; `add_structural_noise` takes the same hooks as echoes.py plus `depth_offset` (unfolded depth of earlier passes)
- `backscatter/dual_element.py` — dual-element (pitch-catch) probe: two prisms at roof angle θ_p with beam entry points ±a (construction parameters; crossing depth z_F = a/tan β is derived, `beam_half_separation` inverts it), Snell refraction β, Gaussian beam overlap → depth sensitivity D(z) = exp(−(a − z·tan β)²/w²) applied at unfolded depth k·d (+ z_i for grain scatterers), V-path 2·sqrt(z²+a²) for arrivals and attenuation, barrier cross-talk κ·(prism train); `synthesize_dual_element_signal` composes cross-talk + backwall train + noise passes; reduces exactly to structural_noise.py at κ = 1, a = 0 (same rng draw order → same microstructure per seed). **Project working assumption (README 8.1, owner's decision 2026-09-08): θ_p = 0 (parallel beams, D = exp(−a²/w²) ≈ 0.37 constant) because the owner's probe П112-10-6/2-А-01 is designated «прямий»; its roof angle / prism length are unpublished and to be verified later (owner plans to check Russian vendor sites via VPN).** Defaults: θ_p = 0, a = 1.5 mm, w = 1.5 mm, κ = 0.01; the crossed-beam scenario of README section 8 uses `CROSSED_BEAM_ROOF_ANGLE` (3.5°) with a from z_F = d
- `backscatter/schematic.py` — draws the measurement-setup schematics with matplotlib (unfolded-time convention, ray slopes ∝ real travel times): bare specimen (README fig. 2), delay-line prism (fig. 4), flawed specimen with three color-coded families (fig. 7); plus a true geometric cross-section of the dual-element probe with exaggerated angles (fig. 16)
- `backscatter/visualization.py` — matplotlib helpers; `plot_signal(..., save_path=)` creates parent dirs automatically
- `images/` — generated figures, committed and embedded in README; always regenerated by code, never edited by hand

## Conventions

- Code, comments, and docstrings: English. Documentation (README): Ukrainian — ALWAYS follow the `readme` skill (.claude/skills/readme/) for style, terminology, enumeration, and referencing rules.
- Every physical claim or default value in the README needs a citation to a verified source; module docstrings explain the physics in the same academic style (English) with derivations of the formulas they implement.
- Physical defaults live as module-level constants (e.g. `DEFAULT_FREQUENCY = 10e6`); every physical parameter is a function argument with such a default. SI units throughout: Hz, seconds, meters; attenuation in dB/m at the carrier frequency.
- Signal functions return `(t, signal)` NumPy array pairs of equal length, `t` in seconds; `add_*` functions accept an optional existing `signal` and return a copy, never mutate the input.
- Prefer general functions with the physical special case as a thin wrapper (e.g. backwall echoes wrap the scatterer-echo train) — the owner extends the model this way.
- Plots display time in microseconds (µs); figure text/labels are Ukrainian in the schematic, English in signal plots.
- When a new model stage is added: implement it in its own module under `backscatter/`, wire it into `main.py`, regenerate figures (`MPLBACKEND=Agg python main.py`), verify numerically against the formulas, and update README (via the `readme` skill) including the roadmap checklist and continuous formula/figure/table numbering.
